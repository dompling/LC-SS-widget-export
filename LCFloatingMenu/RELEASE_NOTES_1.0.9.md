# LCFloatingMenu v1.0.9

本次更新重点增强短视频与单向应用在 LiveContainer 虚拟容器环境下的横竖屏自适应表现，消除转屏后半边白屏的问题。

### 功能与体验增强
- **解除横竖屏限制（自适应旋转）**：
  - 新增「解除横竖屏限制（自适应旋转）」独立开关（默认开启），支持在微珠设置中随时按需开启或关闭。
  - 动态解锁 `UIViewController` 的受支持方向限制（`supportedInterfaceOrientations` 放行横屏支持，`shouldAutorotate` 返回 `YES`），允许抖音、红果等原本锁死竖屏的短视频 App 跟随设备重力感应自适应旋转为横屏。
  - 自动检测并校正转屏时被限制在竖屏宽度的 Window 与根视图尺寸，彻底消除横屏下半边内容、右半边大片白屏/黑屏的布局截断 Bug，让视频播放画面自然铺满屏幕。
- **视觉风格对齐**：
  - 该功能开关完全对齐 iOS 原生设计规范，采用系统原生绿色激活色（`#34C759`）。
