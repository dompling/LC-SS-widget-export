# LCFloatingMenu v1.0.23

### 更新内容

1. 隐藏 app 支持折叠与展开处理，不占用过多位置。
   - 存在 2 个及以上隐藏应用时，列表末尾自动聚合为钱包卡包式的分层堆叠；
   - 轻点堆叠区域平滑散发展开，顶部提供轻巧的收起指示栏，随时折叠收回；
   - 单个隐藏应用保持直观展示，长按隐藏/取消隐藏等手势无缝兼容。

### 验证

- 本地与 GitHub Actions 的 iOS arm64 构建与全量自动化测试（79 项行为测试 + 56 万项几何回归）全绿通过。
- 安装后请在 LiveContainer 的 Tweaks 页面重新签名插件，并重启相关 App。
