# LCFloatingMenu v1.0.13

### 更新内容

- 修复深色模式微珠在浅色宿主 App 中变浅、与展开菜单主题不一致的问题。收起微珠在 iOS 26+ 原生玻璃上加入独立的夜间半透明衬底，并降低过强高光；展开菜单仍保留原有玻璃材质。
- 主题设置与宿主 App 外观隔离：手动日间、手动夜间不再继承 App 的强制界面样式；“跟随系统”优先读取屏幕外观，并对微珠和原生材质应用一致的主题。
- 优化「尺寸与形状」调节体验：调整凹角弧度映射、保持旧默认形状兼容，调整参数时预览区域持续显示。
- 修复微珠凹角弧度滑块调整后视觉变化不明显的问题，扩大可调曲率范围并增加几何回归测试。
- 增加宿主强制日间/夜间、玻璃材质主题和微珠形状边界相关回归测试。

### 验证

- 最新主分支的 GitHub Actions iOS arm64 构建及现有自动化检查已通过。
- UIKit 模拟器主题隔离专项测试已通过；真实 iOS 设备上的原生玻璃外观仍需实测确认。
