# LCFloatingMenu v1.0.15

### 更新内容

- 手指拖动微珠和抽屉时不再一卡一卡：轮廓重算和内容弹出的记账都按屏幕刷新率节流，一帧最多重算一次，中间帧只挪位置不重算，首帧和末帧始终精确。
- 「侧边栏」设置页的滑杆不再每动一格就写一次配置文件。拖动期间数值只留在内存里（预览照样实时跟手），松手或停手后才合并写一次，滑杆因此不再卡顿。
- 微珠上的发光条按参考效果重做：实心条外一层柔和弥散光晕，只有两种颜色——平时蓝色，有更新时红色，明亮模式和夜间模式都一样。关闭「发光光条」后光晕整体消失，只留实心细条。
- 恢复默认后微珠、抽屉的形状与配色与 1.0.14 完全一致。

### 验证

- GitHub Actions 的 iOS arm64 构建与全部自动化检查通过，轮廓与形变的几何回归 568798 条断言全部通过。
- 安装后请在 LiveContainer 的 Tweaks 页面重新签名插件，并重启相关 App。
