# LCFloatingMenu 1.0.5 更新说明

本次更新重点优化微珠待机体验与在用应用视觉指示，进一步降低视觉干扰并提升原生质感。

### 微珠自动淡化与独立控制
- **新增闲置自动淡化开关**：在「悬浮控件」设置中新增「自动淡化」偏好设置开关（默认开启）。
- **待机智能平滑淡化**：微珠在 5 秒无交互后平滑渐变至低透明度待机状态（22%），大幅减少全屏使用与阅读时的视觉干扰。
- **即时触控唤醒**：轻触微珠或轻点屏幕任意有效触控区域，微珠立即在 0.2 秒内平滑恢复完整透明度。
- **自定义保持**：关闭该开关后，微珠将常驻保持用户设定的待命透明度，不再自动淡化。

### 在用 App 状态指示极简化
- **iOS 原生风格小绿点**：彻底去除原先覆盖在图标右下角、易遮挡应用图案的 checkmark 对勾大徽标。
- **轻量状态指示**：改用类似 iOS 通话与前台活动指示风格的纯色高质感小绿点（带 1.0pt 纯白微高光外圈），精确点缀在图标右下角，既保证前台运行状态一目了然，又保持 App 图标完整与美观。

### 横竖屏自适应与微珠贴边修复
- **转屏自适应吸附**：全面重构 Overlay 窗口生命周期与旋转监听机制，解决手机横竖屏切换时微珠未能同步重新布局、导致停留在竖屏绝对物理位置的 bug。
- **物理边缘严丝合缝贴靠**：修正微珠停靠坐标计算，微珠在横屏或安全区变化时紧密贴附于屏幕物理边缘，彻底杜绝因安全区缩进而悬空浮空、不靠边的问题。
- **横屏拖拽边界优化**：修复横屏下微珠拖动手势的活动范围限制，确保横屏下微珠可自如拖动至屏幕最左或最右两端。

### 安装与生效
下载 `LCFloatingMenu.dylib`，在 LiveContainer 中导入插件并重新签名后生效。
