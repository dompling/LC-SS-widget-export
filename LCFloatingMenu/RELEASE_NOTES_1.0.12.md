# LCFloatingMenu v1.0.12

### 更新内容

- 新增「尺寸与形状」独立设置页面，集中管理微珠胶囊和展开菜单的尺寸参数。
- 支持调整菜单上下延展长度、外框圆角半径和凹角弧度，精简模式与列表模式的图标大小可分别设置。
- 提供菜单形状实时预览，调整滑块时立即更新，并保留屏幕边缘微珠预览。
- 支持分别恢复微珠尺寸和菜单尺寸默认值，互不影响；兼容既有配置与默认外观。
- 补充参数边界、左右停靠镜像、布局、存储与 UIKit 回归检查。

### 验证

- 主要功能提交已通过 133 项 UIKit 检查、几何参数边界验证以及 iOS arm64 构建。
- 正式版由 GitHub Actions 再次编译和验证后发布。
- 真机光学效果和 LC 宿主集成仍需设备确认。
