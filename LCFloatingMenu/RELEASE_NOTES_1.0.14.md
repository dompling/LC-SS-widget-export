# LCFloatingMenu v1.0.14

### 更新内容

- 微珠和展开菜单现在是同一个形状在变：菜单从微珠里长出来、收回去也缩回微珠。可以用手指把微珠往里拉着走，松手按拉的距离和力道决定展开还是弹回；已经展开的往屏幕边上拖同样跟手。菜单里的内容会从下往上一个一个弹出来。
- 微珠可以选款式了：胶囊或水滴，凸出宽度、长度、圆角、柔和度都能调。微珠的位置不在设置里调——按住直接拖到想放的地方，松手吸到最近的一边。
- 菜单展开后，长按某个 App 再上下滑，一块玻璃镜片会跟着手指走，松手就切过去，拖出菜单外松手则取消。App 多的时候把手指推到列表上下边缘，列表会自己滚动，不用松手就能选到后面的。
- 新增「侧边栏」设置页（取代原来的「尺寸与形状」）：顶部固定一张预览卡，点一下就能看展开效果，调什么立刻能看到；下面分「位置、把手、透明度、托盘」四组，一次展开一组。整页用的是和菜单同一种玻璃材质。
- 菜单上方改成普通圆角、只有下方顺着屏幕边缘扫出去。顶部留白默认几乎没有，想松一点或者再往上提，用「上方留白」滑杆。
- 顶部那排收藏小图标只在你确实固定过收藏时才出现，不再把下面的列表重复一遍；当前 App 那一行去掉了点不动的箭头和标题里的「· 当前」，图标上的绿灯已经在说这件事。
- 新增这些开关，都在「侧边栏」设置页里，最下面有「恢复默认」：弹出动画（逐个 / 一起 / 关）、停手多久后淡化、淡化后的透明度、图标玻璃底座、发光光条、上方常规圆角、预览底色跟随深浅。

### 验证

- GitHub Actions 的 iOS arm64 构建与全部自动化检查已通过，其中轮廓与形变的几何回归 568798 条断言全部通过。
- 几何另有参考模型逐点比对与变异测试把关；UIKit 模拟器夹具本轮未重跑，玻璃材质在真实 App 背景上的观感以实机为准。
- 安装后请在 LiveContainer 的 Tweaks 页面重新签名插件，并重启相关 App。
